# Chapterly

A private, offline-first book tracker for Android. Built with Flutter.
Inspired by the feature set of openreads (GPL-2.0), with its own code.

## Plan

### Version 1 (MVP)
- Four shelves: Finished, In progress, For later, Unfinished
- Add a book manually (title, author)
- Move a book between shelves
- Tags on books, with filtering

### Next
- Save data to disk (SQLite via drift or sqflite)
- Search Open Library and add books from results
- Barcode scanning
- Ratings, reading dates, and reading time
- Statistics
- CSV import and export (Goodreads, BookWyrm, Chapterly)
- Backup and restore
- Light and dark theme

## Run it

    C:\dev\flutter\bin\flutter.bat run
